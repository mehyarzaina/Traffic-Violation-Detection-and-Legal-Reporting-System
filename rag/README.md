# RAG Integration Setup

## Steps to get the RAG system running with the Flask app

### 1. Add your environment variables to `.env`
```
GROQ_API_KEY=your_groq_api_key_here
GEMINI_API_KEY=your_gemini_api_key_here
DB_USER=...
DB_PASSWORD=...
DB_HOST=...
DB_PORT=...
DB_NAME=...
```

### 2. Place the knowledge base file
Copy `smartpath_jordan_complete_rag.txt` into the `rag/` folder:
```
capstone-project/
└── rag/
    ├── rag_engine.py
    └── smartpath_jordan_complete_rag.txt   ← place it here
```

### 3. Install new dependencies
```bash
pip install chromadb sentence-transformers groq
```
Or install everything:
```bash
pip install -r requirements.txt
```

### 4. Pre-build the ChromaDB index (optional but faster)
Run this once before starting the Flask app:
```bash
python rag/rag_engine.py
```
This creates a `rag/chroma_store/` folder with the vector index.
If you skip this step, the index will be built automatically on first request (takes ~30 seconds).

### 5. Run the Flask app normally
```bash
python app.py
```

## What the integration adds

### On the Detect page
After a violation is detected, a **📜 Legal Report** panel appears below the fine breakdown showing:
- The matching Jordan Traffic Law article ID and title
- The official penalty from the law
- A formal 4-sentence violation report generated by Llama 3.3 (via Groq)

### On the History page
A **🤖 Traffic Law Assistant** chatbot panel appears at the bottom. Officers can type any question about Jordan traffic laws (e.g. "What is the fine for wrong-way driving?") and get an instant answer grounded in the RAG knowledge base.

## How it works

```
Image uploaded
     ↓
YOLO detects violations (e.g. "Wrong Way Driving")
     ↓
RAG: violation name → query → ChromaDB vector search
     ↓
Top 2 matching law articles retrieved
     ↓
Groq LLM (Llama 3.3) generates formal report from articles
     ↓
Report shown on detect page

Officer types question in chatbot
     ↓
Question → ChromaDB vector search (top 3 articles)
     ↓
Groq LLM answers using only retrieved articles
     ↓
Answer shown in chat
```
